## Engineering philosophy

```text
Build → Break → Debug → Understand → Improve
```

I care about what's actually happening below the API layer:

```text
Application → API → Database → Integration → Infrastructure
```

Most of what I've learned professionally came from tracing a bug down
through that chain rather than from a tutorial — so that's the loop I
default to when learning something new too.
